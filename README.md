# Carlos The Snake 🐍

A neon-themed Snake game by ONILABS, built in a single HTML file.

## ▶️ Play

[anthoniriv.github.io/juego-snake](https://anthoniriv.github.io/juego-snake/)

## Controls

- **Keyboard:** arrow keys (or WASD) to move, `Space`/`Enter` to start.
- **Touch:** on-screen D-pad or swipe.

## Tech

- Plain HTML + inline CSS/JavaScript (no framework, no build step).

## Hosting

Hosted on **GitHub Pages** (previously deployed on Vercel).
